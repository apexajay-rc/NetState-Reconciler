# NetState Reconciler v0.3.0 engineering additions

## Added modules
- `transactions.py`: driver-agnostic transaction model with checkpoint, capability allow-list, explicit approval, post-change verification, and rollback on failure. This is a safety primitive, not a production-ready IOS rollback adapter.
- `topology.py`: validates duplicate IPv4 addresses and link endpoint references using a small explicit YAML schema.
- `evaluation.py` and `corpus_eval.py`: confusion-matrix metrics and a repeatable version-labelled corpus evaluation command.
- `inventory.py`: validates a multi-device YAML inventory and performs read-only SSH collection/audits. Passwords come from `NETSTATE_DEVICE_PASSWORD`; secrets must not be committed.
- `scheduler.py`: one-shot or repeated audit runner that writes timestamped JSON reports. Run with `netstate-scheduled-audit --inventory examples/inventory.yaml --interval-seconds 3600`.
- `tests/integration/test_virtual_ios.py`: opt-in live SSH collection integration test. It is skipped unless lab environment variables are provided.

## Honest evidence boundary
The three bundled version-labelled corpus cases are **synthetic IOS-style fixtures**, not captures from IOS 15.2, IOSv 15.9, or IOSv 17.3. They test repeatability and fixture provenance metadata but do not prove compatibility with those releases. Replace them with sanitized, real captures and label exact image/version/build before claiming version support.

The live integration test requires a reachable IOS-compatible SSH lab and credentials. It is intentionally skipped in default CI; no virtual IOS lab was available during this build, so stateful live-device behavior is unverified. The transaction model is tested with a fake driver, not a real device rollback implementation. Topology checks are basic invariants, not full routing reachability analysis. Corpus false-positive/false-negative metrics are only meaningful when labels and fixtures represent representative real cases.

## Commands
```bash
netstate-evaluate-corpus --manifest tests/corpus/manifest.yaml --desired configs/router1.yaml
netstate-scheduled-audit --inventory examples/inventory.yaml --output-dir reports/scheduled --interval-seconds 3600
```

Install optional SSH support with `python -m pip install -e '.[ssh]'`. Set `NETSTATE_DEVICE_PASSWORD` in the environment before scheduled inventory audits. The sample inventory uses TEST-NET IP `192.0.2.10`; replace it with a lab device address.
